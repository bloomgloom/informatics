# **인공지능 기초 수행평가 안내**

## **영역**

인공지능 모델을 활용하여 데이터를 분석하는 프로그래밍하기\
➡ 기계학습 및 딥러닝 모델을 활용하여 데이터를 전처리한 후 학습하여 평가하는 프로그램 작성하기

## **일시**

| 학급 | 1, 7, 8 | 2, 4 | 3, 5, 6 |
| :---: | :---: | :---: | :---: |
| 일자 | **10월 15일 (목)** | **10월 15일 (목)** | **10월 15일 (목)** |
| 교시 | **1교시** | **5교시** | **6교시** |

※ 변동 가능

## **장소**

컴퓨터실

## **준비물**

<mark>검정색 볼펜</mark>\
일찍 끝나는 경우, 제출 후 자습 가능 ➡ 미리 준비

## **점수**

20점 만점, 기본점수 8점, 항목당 2점

**평가 요소**

>1. 데이터 탐색 및 전처리 요소를 활용하여 프로그래밍할 수 있는가?
>2. 회귀 모델을 활용하여 프로그래밍할 수 있는가?
>3. 분류 모델을 활용하여 프로그래밍할 수 있는가?
>4. 군집 모델을 활용하여 프로그래밍할 수 있는가?
>5. 신경망 모델을 활용하여 프로그래밍할 수 있는가?
>6. 합성곱 신경망을 활용하여 프로그래밍할 수 있는가?

| 수행 수준(채점 기준) | 배점 |
| ----- | :---: |
| 평가 요소 중 6가지 요소를 만족함 | 20 |
| 평가 요소 중 5가지 요소를 만족함 | 18 |
| 평가 요소 중 4가지 요소를 만족함 | 16 |
| 평가 요소 중 3가지 요소를 만족함 | 14 |
| 평가 요소 중 2가지 요소를 만족함 | 12 |
| 평가 요소 중 1가지 요소를 만족함 | 10 |
| 평가 요소 중 모두 만족하지 못함                                                                  **(기본점수)** | 8 |
| **장기 미인정결시자(기본점수-1점)** | 7 |

## **유의 사항**

1. 종이 활동지에 검정색 펜으로 코드 작성. 수정 시 펜으로 두 줄 긋고 이어서 작성 (**<mark>교과서 참고, 컴퓨터 사용 등 불가</mark>**)
2. 연습용으로 배포된 데이터(.csv)와 활동지(.ipynb)를 기준으로 출제됨.
3. 문항은 활동지의 일부 단계만 추출하여 출제함.
4. 파일명, 변수명, 열 이름, 조건 등은 배포된 데이터/활동지와 다를 수 있음. 제시되는 문항을 바탕으로 작성할 것
5. 라이브러리 import 코드는 작성하지 않아도 됨. (채점에 반영하지 않음.)
