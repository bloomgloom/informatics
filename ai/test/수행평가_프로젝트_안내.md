# **인공지능 기초 수행평가 안내**

## **영역**

실생활 문제를 해결하는 인공지능 프로젝트 제작하기\
➡ 실생활 문제를 정의하고, 데이터를 수집하여 전처리하고, 인공지능 모델을 구성하여 학습하고 평가하기

## **일시**

| 학급 | 1, 7, 8 | 2, 4 | 3, 5, 6 |
| :---: | :---: | :---: | :---: |
| 일자 | **10월 22일 (목)** | **10월 22일 (목)** | **10월 22일 (목)** |
| 교시 | **1교시** | **5교시** | **6교시** |

※ 변동 가능

## **장소**

컴퓨터실

## **준비물**

수업 시간에 미리 제출한 데이터 파일(csv)은 교사가 배부\
일찍 끝나는 경우, 제출 후 자습 가능 ➡ 미리 준비

## **점수**

20점 만점, 기본점수 8점, 항목당 2점

**평가 요소**

>1. 해결할 문제를 스스로 정의할 수 있는가?
>2. 문제에 맞는 데이터를 직접 수집할 수 있는가?
>3. 수집한 데이터를 분석·학습에 맞게 전처리할 수 있는가?
>4. 문제에 맞는 모델을 구성할 수 있는가?
>5. 구성한 모델을 학습시킬 수 있는가?
>6. 학습한 모델의 성능을 평가할 수 있는가?

| 수행 수준(채점 기준) | 배점 |
| ----- | :---: |
| 평가 요소 중 6가지 요소를 만족함 | 20 |
| 평가 요소 중 5가지 요소를 만족함 | 18 |
| 평가 요소 중 4가지 요소를 만족함 | 16 |
| 평가 요소 중 3가지 요소를 만족함 | 14 |
| 평가 요소 중 2가지 요소를 만족함 | 12 |
| 평가 요소 중 1가지 요소를 만족함 | 10 |
| 평가 요소 중 모두 만족하지 못함                                                                  **(기본점수)** | 8 |
| **장기 미인정결시자(기본점수-1점)** | 7 |

## **유의 사항**

1. 오프라인으로 실시 (**<mark>인터넷 검색, 구글 클래스룸 활용, 코드 참고 등 불가</mark>**)
2. Visual Studio Code를 사용하여 Jupyter Notebook(.ipynb) 활동지에 글/코드를 작성하여 제출(실행 결과 포함)
3. 활동지는 미리 공개하나, **활동지나 종이에 미리 작성해 올 수 없음**
4. 사용한 데이터 파일(csv)도 함께 제출
