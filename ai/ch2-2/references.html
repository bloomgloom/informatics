데이터 준비

1-1데이터 로드

pd.read_csv()

세 유형 공통

import pandas as pd

df = pd.read_csv('파일명.csv')       # csv 파일 → 데이터프레임

1-2데이터 확인

df.head() / .info() / .shape / .describe()

세 유형 공통

df.head()            # 앞 5행 미리보기
df.info()            # 속성 수 · 자료형 · 결측치 여부
df.shape             # (행 수, 열 수)
df.describe()        # 평균 · 표준편차 등 통계 요약

1-3새 속성 만들기

(필요한 경우)df['새 열'] = 기존 열에서 뽑아낸 값

세 유형 공통

# 날짜에서 연도만 뽑아내기 (선택활동1)
df['연도'] = pd.to_datetime(df['시간']).dt.year

# 문자열의 앞부분만 뽑아내기 (선택활동1)
df['지역'] = df['위치'].str[:3]

※ .dt → 날짜 요소(year · month · day · hour)에 접근.str → 문자열 처리 기능에 접근

전처리

2-1결측치 확인 및 제거

isnull().sum() → dropna()

세 유형 공통

df.isnull().sum()                   # 열별 결측치 개수 확인
df.dropna(axis=0, inplace=True)     # 결측치가 있는 '행' 삭제

※ axis=0 : 행 단위 / inplace=True : 원본 df에 바로 반영

2-2이상치 확인 및 제거

boxplot / unique() → drop()

세 유형 공통

sns.boxplot(data=df, x='수치형 열')    # 상자그림으로 크게 벗어난 값 확인
df['범주형 열'].unique()               # 잘못 입력된 값 확인 (예: '.')

df[df['열'] == '이상값']               # 해당 행의 인덱스 찾기
df.drop(인덱스, axis=0, inplace=True)  # 그 행 삭제

2-3정규화

MinMaxScaler().fit_transform()

세 유형 공통

from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()

새 변수에 담기

X_scaled = scaler.fit_transform(X)   # 원본 df 는 그대로 두고 정규화된 값만 따로

원본 열에 덮어쓰기

df[['열1', '열2', '열3']] = scaler.fit_transform(df[['열1', '열2', '열3']])   # 고른 열만 0~1 로 바뀜

※ 정규화한 값을 쓰려면 다음 단계에 그 결과를 넣어야 함새 변수에 담았으면 → X_scaled 를 사용원본에 덮어썼으면 → df 에서 뽑은 X 가 이미 정규화된 상태

※ 속성마다 값의 크기 차이가 클 때 필요 (예: 부리 깊이 17 vs 체질량 4200)사용 여부 → 회귀: 사용 안 함 | 분류(kNN·로지스틱): 사용 | 군집: 사용(거리 기반)

2-4데이터 마련

(X, y 선정)X = 입력 / y = 정답

회귀 · 분류 공통

X = df[['열1', '열2', ...]]           # 여러 개 선택
y = df['정답 열']

※ 용어만 다르고 코드는 같음회귀 → X: 독립변수, y: 종속변수(연속적인 수)분류 → X: 특징, y: 타깃(범주 · 클래스)

data = df[['열1', '열2']]     # 사용할 특징만 선택

※ 비지도학습이므로 정답(y)을 만들지 않음

2-5분할

train_test_split(X, y, test_size=0.3)

회귀 · 분류 공통

from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

※ 추가 옵션random_state=42 → 실행할 때마다 같은 분할 결과 (회귀·분류 공통)stratify=y → 클래스 비율을 원본과 같게 유지 (분류에서만 사용)

※ 분할 단계 없음 (정답이 없으므로 전체 데이터로 학습)

model = KMeans(n_clusters=k)   # 군집 개수 k 지정

3-2모델 내부 값 확인

model.속성_
model.coef_        # 회귀계수(기울기)
model.intercept_   # 절편

→ 회귀식 ŷ = coef_ × x + intercept_

model.classes_          # 분류할 클래스 목록
model.coef_             # 특징별 계수(로지스틱)
model.labels_           # 각 데이터의 군집 번호
model.cluster_centers_  # 각 군집의 중심값

df['cluster'] = model.labels_

평가

4-1예측

model.predict()

회귀 · 분류 공통

pred = model.predict(X_test)    # 테스트 데이터로 예측

※ 회귀 → 연속적인 수를 예측 | 분류 → 클래스(범주)를 예측

pred = model.predict(data)
# 각 데이터가 속한 군집 번호

4-2평가

model.score() / 평가 지표 함수

회귀 · 분류 공통

model.score(X_test, y_test)

※ 같은 코드지만 결과의 의미가 다름회귀 → 결정계수 R² (1에 가까울수록 잘 설명)분류 → 분류 정확도 (맞힌 비율)

# 분류는 혼동행렬로 오답 패턴까지 확인
from sklearn.metrics import confusion_matrix
conf = confusion_matrix(y_test, pred)
from sklearn.metrics import silhouette_score
silhouette_score(data, model.labels_)

→ 실루엣 점수 (1에 가까울수록 잘 분리)

※ 정답이 없어 score() 사용 불가
