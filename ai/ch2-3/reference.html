1문제 정의 · 데이터 수집
1-1 분류할 대상입력 특징(X)과 정답(y)

수치형 특징 2개

당도(sweet), 아삭함(crunchy) → 과일·단백질·채소 3종

28×28 픽셀

흑백 손글씨 이미지 → 숫자 0~9, 총 10종

도로 이미지

균열 없음(Negative) · 균열 있음(Positive), 총 2종

1-2 데이터 불러오기
import pandas as pd
df = pd.read_csv('food_nn.csv')
X = df[['sweet', 'crunchy']].to_numpy()
y = df['class'].to_numpy()

이 예제는 분할 없이 전체 데이터로 구현 절차를 연습한다.

from tensorflow import keras
(X_train, y_train), (X_test, y_test) = keras.datasets.mnist.load_data()

훈련 이미지 60,000장, 테스트 이미지 10,000장으로 제공된다.

from pathlib import Path
data_dir = Path('crack')
# crack/train/Negative, crack/train/Positive
# crack/test/Negative,  crack/test/Positive

실습 데이터: 훈련 300장, 테스트 80장. Colab에서는 data_dir을 드라이브의 crack 폴더로 바꾼다.

2데이터 전처리
2-1 모델 입력 준비이미지는 픽셀값을 0~1로 변환
loss_name = 'sparse_categorical_crossentropy'

sweet·crunchy 두 열을 그대로 입력한다. 정답은 0·1·2의 정수 레이블이다.

X_train = X_train / 255.0
X_test = X_test / 255.0
loss_name = 'sparse_categorical_crossentropy'

각 이미지의 28×28 모양은 유지한다. 정답은 0~9의 정수 레이블이다.

from tensorflow.keras.preprocessing.image import ImageDataGenerator
generator = ImageDataGenerator(rescale=1 / 255)
train_set = generator.flow_from_directory(
    data_dir / 'train', target_size=(224, 224),
    class_mode='categorical')
test_set = generator.flow_from_directory(
    data_dir / 'test', target_size=(224, 224),
    class_mode='categorical', shuffle=False)
loss_name = 'categorical_crossentropy'

train·test에 같은 픽셀 변환을 적용한다. 테스트 순서는 예측 결과와 실제 레이블을 맞추기 위해 유지한다.

3모델 설계
3-1 모델과 계층출력 노드 수 = 클래스 수

2 → 32 → 16 → 3

from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense
model = Sequential([
    Dense(32, activation='relu', input_shape=(2,)),
    Dense(16, activation='relu'),
    Dense(3, activation='softmax')
])

두 입력값을 완전 연결 계층(Dense)에 바로 넣는다.

28×28 → 784 → 128 → 64 → 10

from tensorflow.keras import Sequential
from tensorflow.keras.layers import Flatten, Dense
model = Sequential([
    Flatten(input_shape=(28, 28)),
    Dense(128, activation='relu'),
    Dense(64, activation='relu'),
    Dense(10, activation='softmax')
])

Flatten이 2차원 픽셀을 784개 값으로 펼친다.

VGG16 → 펼치기 → 64 → 2

from tensorflow.keras.applications import VGG16
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Flatten, Dense
vgg = VGG16(weights='imagenet', include_top=False,
            input_shape=(224, 224, 3))
vgg.trainable = False
model = Sequential([vgg, Flatten(),
                    Dense(64, activation='relu'),
                    Dense(2, activation='softmax')])

고정한 VGG16이 이미지 특징을 추출하고, 새 Dense 계층이 분류한다.

4환경 설정 · 학습
4-1 compile()세 모델 공통 호출

세 모델 공통

model.compile(optimizer='adam', loss=loss_name, metrics=['accuracy'])

최적화 함수와 평가 지표는 동일하다. 손실함수는 앞 단계에서 정답 레이블 형태에 맞게 지정했다.

4-2 fit()반복 학습 횟수(epochs)
history = model.fit(X, y, epochs=500)

작은 식품 데이터 전체로 학습한다.

history = model.fit(X_train, y_train, epochs=10)

훈련 데이터 60,000장으로 학습한다.

history = model.fit(train_set, epochs=5)

VGG16 가중치는 유지하고 새 분류 계층을 학습한다.

5평가 · 예측
5-1 evaluate()손실(loss)과 정확도(accuracy)
loss, accuracy = model.evaluate(X, y)

학습 데이터로 평가하므로 새 식품에 대한 성능으로 해석하지 않는다.

loss, accuracy = model.evaluate(X_test, y_test)

학습에 쓰지 않은 테스트 데이터로 확인한다.

loss, accuracy = model.evaluate(test_set)

훈련 정확도와 테스트 정확도를 비교한다.

5-2 predict()클래스별 확률에서 최댓값 찾기
import numpy as np
probabilities = model.predict(X)
predicted = np.argmax(probabilities, axis=1)

식품마다 과일·단백질·채소 확률 3개가 나온다.

import numpy as np
probabilities = model.predict(X_test)
predicted = np.argmax(probabilities, axis=1)
print(predicted[0], y_test[0])

숫자마다 0~9 확률 10개가 나온다.

import numpy as np
probabilities = model.predict(test_set)
predicted = np.argmax(probabilities, axis=1)
print(train_set.class_indices)

Negative=0, Positive=1. 예측 확률 2개 중 큰 값의 클래스를 고른다.

import matplotlib.pyplot as plt
plt.plot(history.history['loss'])

반복 학습에 따라 손실이 어떻게 변했는지 확인한다. 식품 노트북에는 별도 시각화 단계가 없어 학습 기록을 그래프로 나타냈다.

import matplotlib.pyplot as plt
plt.imshow(X_test[0], cmap='gray')
plt.title(f'Actual: {y_test[0]} / Predicted: {predicted[0]}')
plt.axis('off')
plt.show()

실습5처럼 손글씨 이미지를 표시하고 실제 숫자와 예측 숫자를 비교한다.

from sklearn.metrics import confusion_matrix
import seaborn as sns
import matplotlib.pyplot as plt
conf = confusion_matrix(test_set.classes, predicted)
sns.heatmap(conf, annot=True, fmt='d', cmap='Blues',
            xticklabels=['Negative', 'Positive'],
            yticklabels=['Negative', 'Positive'])
plt.xlabel('Predicted')
plt.ylabel('Actual')
plt.show()

혼동 행렬로 어떤 종류의 오분류가 있었는지 확인한다.
