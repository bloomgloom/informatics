1-2Kaggle

kaggle.com/datasets는 전 세계 사람들이 올린 데이터셋 모음입니다. 주제가 매우 다양하고 대부분 CSV라 바로 쓰기 좋지만, 회원 가입(로그인)이 있어야 다운로드할 수 있고 설명이 영어입니다.

CSV 받는 방법

  1. 로그인한 뒤 검색창에 영어 키워드를 넣습니다 (예: air quality korea, bike sharing).
  2. 데이터셋 페이지에서 Download 버튼을 누르면 zip 파일로 받아집니다.
  3. 압축을 풀어 CSV를 꺼내고, Colab 왼쪽 파일 탭에 올린 뒤 pd.read_csv('파일명.csv')로 읽습니다.

지역 데이터 포털

우리 지역 문제를 다루고 싶다면 지역 포털을 먼저 찾아봅니다. 서울 열린데이터광장, 경기데이터드림, 인천데이터포털, 부산 빅데이터웨이브 등이 있고, 다른 시·도도 이름에 "데이터"나 "열린데이터"가 들어간 포털을 운영하는 경우가 많습니다.

※ 음원·앨범 차트는 공식 API가 없어 웹 페이지에서 직접 모아야 하고, 곡의 음향 특성(템포, 에너지 등)은 제공하지 않습니다. 멜론·지니도 공식 API가 없으므로 모으기 전에 이용 약관을 확인해야 합니다.

1-4데이터를 받기 전에 확인할 것

  • API 키는 미리 신청합니다. 공공데이터포털 등은 승인이나 키 활성화에 시간이 걸릴 수 있습니다. 파일(CSV) 내려받기가 있으면 그쪽이 더 간단합니다.
  • 받은 데이터는 CSV로 저장해 둡니다. 수업 중에 API를 매번 호출하면 호출 제한이나 네트워크 문제로 막힐 수 있습니다.
  • 공식 API가 없는 사이트(써클차트, 멜론, 지니 등)는 모으기 전에 약관을 확인합니다.
  • 빈 칸과 이상한 값이 얼마나 있는지 봅니다. 공공 데이터는 빈 칸이나 형식이 깨진 행이 흔합니다. 숫자처럼 보이는데 "5.2(Kg)"처럼 단위가 붙어 있는 열도 있습니다.
  • 행 수가 충분한지 봅니다. 연도별 합계처럼 행이 수십 개뿐이면 월별·지역별·시간대별 자료를 찾아 수천 개로 늘립니다.
  • 출처를 적어 둡니다. 사이트 이름, 데이터 이름, 주소, 받은 날짜.

주제 정하기

2-1관심 분야 → 질문 → 맞힐 값으로 좁히기

데이터부터 고르면 오히려 질문이 떠오르지 않습니다. 급식, 게임, 음악, 지하철, 날씨처럼 매일 겪는 것에서 출발해 세 단계로 좁힙니다.

관심 분야자전거, 날씨
→
궁금한 질문비 오는 날에는 따릉이를 얼마나 덜 탈까?
→
맞힐 값(타깃)시간대별 대여량 → 숫자 → 회귀
→
필요한 데이터서울 열린데이터광장 대여 기록 + 기상자료개방포털 강수량

질문이 잘 안 나오면 아래 세 문장 중 하나에 넣어 봅니다.

  • "◯◯는 얼마나 될까?" → 회귀
  • "이건 어느 쪽일까?" → 분류
  • "어떤 유형들이 있을까?" → 군집

2-2주제를 넓히는 방법

  • 데이터 두 개를 합칩니다. 따릉이 대여량에 날씨를 붙이면 "비 오는 날 얼마나 줄어드는가"가 됩니다. 미세먼지에 기상 데이터, 박스오피스에 개봉 시기나 경쟁작 수를 붙이는 식입니다. 합치는 순간 질문이 훨씬 구체적으로 바뀝니다.
  • 예측이 빗나가는 지점을 찾아봅니다. 2020년 교통사고, 역주행한 노래, 예상 밖으로 흥행한 영화처럼 패턴에서 벗어난 사례를 보면 "모델은 과거만 배운다"는 한계를 직접 확인할 수 있습니다. 평가 단계에서 개선 방향을 쓸 때도 좋은 소재가 됩니다.
  • 데이터부터 구할 수 있는지 확인합니다. 주제가 좋아도 데이터가 없으면 진행할 수 없습니다. 주제를 정하면 바로 해당 사이트에 들어가 몇 행이나 받을 수 있는지 먼저 봅니다.

2-3주제 점검표

진행할 수 있는 주제

  • 데이터를 실제로 내려받아 열어 보았다
  • 행이 적어도 수백 개 있다
  • 맞히고 싶은 값이 열로 들어 있다 (군집이라면 묶을 기준이 될 숫자 열이 여러 개 있다)
  • 그 값을 짐작하게 해 줄 다른 열이 여러 개 있다
  • 열 이름의 뜻을 설명할 수 있다

다시 생각해 볼 주제

  • "찾으면 있겠지" 하고 아직 데이터를 보지 않았다
  • 연도별 합계뿐이라 행이 수십 개다
  • 맞히려는 값이 어디에도 기록되어 있지 않다
  • 정답 열을 알면 바로 답이 나오는 질문이다 (3-2의 데이터 누수)
  • 개인을 알아볼 수 있는 정보가 필요하다

특징(feature)·타깃(target) 정하기

3-1타깃을 보면 방법이 정해진다

타깃은 모델이 맞혀야 할 값(정답, y)이고, 특징은 그 값을 맞히는 데 쓰는 입력(X)입니다. 타깃이 어떤 값인지에 따라 회귀·분류·군집이 갈립니다.

타깃방법예
숫자 (크기가 의미 있는 값)회귀관객 수, 아파트 가격, 미세먼지 농도
범주 (몇 가지 중 하나)분류경기 승패, 입양 여부, 사고 심각도, 펭귄 종

3-2특징 고르는 요령

타깃을 미리 알려 주는 열은 뺀다 (데이터 누수)

타깃과 사실상 같은 내용이거나, 타깃이 정해진 뒤에야 알 수 있는 열을 특징에 넣으면 점수는 높게 나오지만 실제로는 쓸 수 없는 모델이 됩니다.

  • seaborn 타이타닉 데이터의 alive 열은 survived(생존 여부)와 같은 내용입니다. 생존 여부를 맞힐 때 넣으면 안 됩니다.
  • 유기동물의 입양 여부를 맞히면서 "보호 종료일"을 넣으면, 입양된 날을 미리 알려 주는 셈입니다.
  • 점검 질문: "예측하는 순간에 이 값을 알 수 있는가?"

행을 구별하기 위한 번호는 뺀다

관리번호, 일련번호, 고객 번호처럼 행마다 붙인 번호는 숫자여도 타깃과 아무 관계가 없습니다. 이런 열이 특징에 들어가면 모델이 의미 없는 규칙을 배웁니다.

상관관계를 확인한다

회귀에서는 타깃과 상관계수가 큰(절댓값이 1에 가까운) 열이 좋은 후보입니다. 서로 거의 같은 내용인 특징 두 개(예: 키(cm)와 키(m))는 하나만 남깁니다.

corr = df.corr(numeric_only=True)          # 숫자 열끼리 상관계수
corr['body_mass_g'].sort_values().round(2)   # 타깃과의 상관계수만 보기

sns.heatmap(corr, annot=True, cmap='coolwarm')  # 한눈에 보기
bill_depth_mm -0.47 bill_length_mm 0.60 flipper_length_mm 0.87 body_mass_g 1.00

※ 펭귄 몸무게를 맞힌다면 날개 길이(0.87)가 가장 유력한 특징입니다. 상관계수는 직선 관계만 보여 주므로, 낮다고 바로 버리지 말고 산점도도 함께 봅니다.

3-3특징·타깃을 코드로 정하고 나누기

정한 특징과 타깃을 X, y에 담고 훈련용과 테스트용으로 나눕니다. 2-2 실습과 같은 방식입니다.

df = df.dropna()   # 결측치가 있는 행 정리
X = df[['bill_length_mm', 'bill_depth_mm', 'flipper_length_mm', 'body_mass_g']]   # 특징
y = df['species']                                                              # 타깃

from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

※ 군집은 타깃이 없으므로 data = df[['열1', '열2']]처럼 특징만 고르고, 나누지 않습니다.
※ 이후 단계(정규화, 학습, 평가)의 코드 패턴은 2-2 참고 자료를 봅니다.

5

신경망으로 분류할 때 — 타깃을 원-핫 인코딩으로

5-1왜 바꾸나

2-3에서 만든 신경망 분류 모델은 출력층 노드 수가 클래스 수와 같고, softmax가 클래스마다 확률을 하나씩 내놓습니다. 그래서 정답도 같은 모양, 즉 맞는 클래스 자리만 1이고 나머지는 0인 줄로 바꿔 줍니다. 이것을 원-핫 인코딩이라고 합니다. 원-핫 타깃은 손실 함수 'categorical_crossentropy'와 함께 씁니다. 2-3처럼 정수 번호 타깃을 쓸 때는 'sparse_categorical_crossentropy'를 씁니다.

정답 (원-핫 타깃)
AdelieChinstrapGentoo
100
⇄
모델 출력 (softmax 확률, 합 = 1)
AdelieChinstrapGentoo
0.8260.1660.008

학습은 모델이 내놓는 확률을 정답 줄에 가깝게 만드는 과정이고, 예측할 때는 가장 큰 확률의 자리(argmax)를 골라 다시 클래스 이름으로 바꿉니다.

클래스 수출력층타깃 모양손실 함수
3 (펭귄 종)Dense(3, activation='softmax')행마다 0·1 세 개'categorical_crossentropy'

5-2펭귄 종 분류 신경망 예시

① 데이터 준비 · 타깃 원-핫 인코딩

import seaborn as sns
import pandas as pd
df = sns.load_dataset('penguins')
df = df.dropna()

X = df[['bill_length_mm', 'bill_depth_mm', 'flipper_length_mm', 'body_mass_g']].to_numpy()

y_onehot = pd.get_dummies(df['species'], dtype=int)   # 종 이름 → 0·1 열 3개
y = y_onehot.to_numpy()
y_onehot.head(3)
Adelie Chinstrap Gentoo 0 1 0 0 1 1 0 0 2 1 0 0

※ y_onehot.columns에 열 순서(Adelie, Chinstrap, Gentoo)가 남아 있습니다. 마지막에 예측 결과를 종 이름으로 되돌릴 때 씁니다.

② 분할 · 정규화

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

scaler = MinMaxScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

③ 모델 설계 · 학습 (출력 노드 3개 = 종 3개)

from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense
model = Sequential([
    Dense(16, activation='relu', input_shape=(4,)),
    Dense(8, activation='relu'),
    Dense(3, activation='softmax')
])
model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])
history = model.fit(X_train, y_train, epochs=100)
loss, accuracy = model.evaluate(X_test, y_test)

④ 예측 확률 → 종 이름으로 되돌리기

import numpy as np
probabilities = model.predict(X_test)           # 펭귄마다 확률 3개
predicted = np.argmax(probabilities, axis=1)    # 가장 큰 확률의 자리: 0, 1, 2

names = y_onehot.columns                          # ['Adelie', 'Chinstrap', 'Gentoo']
print(list(names[predicted][:5]))                 # 예측한 종 이름
print(list(names[np.argmax(y_test, axis=1)][:5]))  # 실제 종 이름
['Adelie', 'Gentoo', 'Adelie', 'Chinstrap', 'Adelie'] ['Adelie', 'Gentoo', 'Adelie', 'Chinstrap', 'Adelie']

※ 테스트 정확도는 실행할 때마다 조금씩 다르며, 직접 실행해 보았을 때 0.98~0.99였습니다. 실제 정답 y_test도 원-핫 모양이므로 같은 방법(argmax)으로 이름을 되돌려 비교합니다.
