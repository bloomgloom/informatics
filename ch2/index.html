문자열 압축

반복되는 문자나 패턴을 더 적은 비트로 표현하는 비손실 압축

1

런-렝스 인코딩

동일한 문자가 연속해서 반복되는 경우, 그것을 반복 문자 개수와 반복 문자의 쌍으로 표현

COFFEEEEEE FREEE
CO2F6E FR3E
알고리즘 단순
반복 문자가 길수록 압축 효율 높음
2

렘펠-지브 인코딩

문자열에 포함된 같은 패턴의 상대적 위치와 패턴의 길이로 문자열을 치환하여 압축

WELCOME COMPANY
WELCOME (5, 3)PANY
떨어져 있는 같은 패턴 압축 가능
반복 패턴이 많은 긴 문자열에서 압축 효율 높음

02

p.41

런-렝스 인코딩 시뮬레이션

연속해서 반복되는 문자를 개수와 문자로 바꾸어 압축한다

원래 문자열

COFFEEEEEE빈칸FREEE
압축 후 문자열
CO2F6E FR3E

단계

  1. 반복이 없는 `C`, `O`는 그대로 기록
  2. `FF`는 `2F`로 기록
  3. `EEEEEE`는 `6E`로 기록
  4. 빈칸과 반복 없는 `F`, `R`은 그대로 기록
  5. `EEE`는 `3E`로 기록

렘펠-지브 인코딩 시뮬레이션

이미 나온 패턴을 현재 위치 기준의 거리와 길이로 표현한다

원래 문자열

WELCOME COMPANY
현재 위치 C
왼쪽으로 5칸 5
반복 길이 3
압축 후 문자열
WELCOME (5, 3)PANY

단계

  1. `WELCOME`까지 그대로 기록
  2. 현재 위치 `C`에서 왼쪽을 탐색
  3. 5문자 앞에서 같은 패턴 `COM` 발견
  4. 반복 패턴 길이 3을 확인
  5. `COM`을 `(5, 3)`으로 치환

빅데이터 분석

탐색적 데이터 분석으로 문제를 정의하고, 수집·분석·평가한다

1

문제 정의

분석 필요성, 요구 사항, 분석 범위를 파악해 구체적인 목적을 정한다.

2

데이터 수집

목적에 맞는 데이터를 자동 수집기, 인터넷 검색, 설문·실험·관찰로 모은다.

균형 · 개인정보 · 편향성 · 저작권 확인
3

데이터 분석

전처리

평균·중앙값·최빈값을 확인하고 결측치, 중복값, 이상치를 정리한다.

시각화·분석

시간, 관계, 비교 시각화로 흐름·관계·패턴을 찾아 해석한다.

4

공유 및 평가

분석 결과가 의사 결정에 도움을 주는지 검토하고 개선책을 제시한다.

탐색적 데이터 분석(EDA)

데이터를 여러 관점에서 관찰해 구조적 관계를 찾는 분석법

시각화 유형

선그래프·막대그래프·버블 차트·산점도·히트맵·워드 클라우드
