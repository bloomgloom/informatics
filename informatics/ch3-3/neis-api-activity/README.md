# 오늘 급식 뭐야? 나이스 API 수업 서버

학생들이 우리 학교 급식 데이터를 가져와 작은 함수들로 조립하며 API, JSON, 함수를 배우는 수업에 쓰는 서버와 노트북입니다.
서버는 교사 컴퓨터에서 실행하며, 실제 키를 학생에게 주지 않고 학교 코드를 채워 주며 같은 요청을 모아 처리합니다.
서버 실행에는 파이썬만 있으면 됩니다.

```
학생 코드 -> 교사 서버 -> 나이스 API
```

| 파일 | 내용 |
|---|---|
| `server.py` | 서버 |
| `setup.sh` / `setup.bat` | `config.json` 만들기 (Mac / Windows) |
| `start.sh` / `start.bat` | 수업 때 서버 켜기 (Mac / Windows) |
| `notebooks/급식_API_활동지.ipynb` | 학생용. 코드 없이 빈 칸만 있고, 교사 설명을 들으며 따라 칩니다. 일부 함수는 직접 만듭니다. |
| `notebooks/급식_API_해설지.ipynb` | 교사용. 코드가 채워져 있습니다. 학생에게 주지 않습니다. |

**활동지는 클래스룸 등으로 따로 나눠 줍니다.** 해설지는 학생에게 주지 않습니다.

## 수업 흐름

1. **급식 (따라 하기)**: `get_meal` → `clean_menu` → `has_food` → `get_calories`(직접 만들기) → `show_meal` → `week_menu` → `next_food`
2. **이런 것도 가능해요 (학생 활동)**: 시간표 준비물, 시험 D-day, 우산 조언, 미세먼지 등급, 급식 분석, 아침 브리핑 중에서 골라 직접 만듭니다.

## 설정: setup (처음 한 번)

```bash
./setup.sh
```

`config.example.json`으로 `config.json`을 만듭니다. Windows는 `setup.bat`을 더블클릭합니다. 묻는 것은 없습니다.

### 나이스 인증키

키가 없어도 동작하지만 **응답이 5건으로 잘리고 다음 쪽도 볼 수 없습니다.** (2026-11-01 실제 호출로 확인)

| 활동 | 키 없이 |
|---|---|
| 날짜별 급식 (따라 하기 전체) | 가능 |
| 시간표 | **5교시까지만 나옴** |
| 학사일정, 한 번에 여러 날 조회 | 앞 5건만 나옴 |

시간표나 학사일정 활동을 하려면 나이스 교육정보 개방 포털(open.neis.go.kr)에서 인증키를 신청해 넣습니다.

## 수업: start

```bash
./start.sh
```

나이스 인증키(Enter: 키 없이)를 묻고 학교를 검색해 고릅니다. **키와 학교는 파일에 저장하지 않아 켤 때마다 입력합니다.** 그 뒤 접속 주소와 수업용 키를 화면에 안내합니다. 이 내용을 학생들에게 알려 줍니다.

- 수업용 키는 `lunch-tiger-piano`처럼 짧은 영어 단어이며, **서버를 켤 때마다 바뀝니다.** 파일에 저장하지 않습니다.
- 수업이 끝나면 터미널 창에서 `Ctrl+C`로 끕니다.

## 설정 파일

`config.json`은 setup이 `config.example.json`을 복사해 만들고, git에서 제외됩니다. 값을 바꾸려면 이 파일을 직접 고칩니다. 키와 학교는 저장하지 않습니다.

| 항목 | 뜻 |
|---|---|
| `port` | 서버 포트 |
| `limit_per_minute` | 학생(IP) 한 명의 분당 요청 수 |
| `max_concurrent` | 동시에 나이스로 보내는 호출 수. 나머지 요청은 줄 서서 기다림 |
| `cache_seconds` | 같은 요청의 답을 재사용할 시간 |

## 지원하는 API

나이스 API와 같은 형식입니다. `KEY`에는 수업용 키를 넣습니다. `Type`은 항상 `json`으로 보냅니다.

| 주소 | 내용 | 학교 코드 |
|---|---|---|
| `GET /hub/mealServiceDietInfo` | 급식 | 안 넣으면 우리 학교 |
| `GET /hub/hisTimetable` | 고등학교 시간표 | 안 넣으면 우리 학교 |
| `GET /hub/SchoolSchedule` | 학사일정 | 안 넣으면 우리 학교 |
| `GET /hub/schoolInfo` | 학교 검색 | 채우지 않음 |
| `GET /` | 접속 테스트. 키가 필요 없습니다. | |

날씨와 미세먼지 활동은 Open-Meteo로 학생 컴퓨터에서 바로 요청합니다. 키가 필요 없고, 교사 서버를 거치지 않습니다.

## 학생 컴퓨터에서 접속이 안 될 때

- **코랩은 접속할 수 없습니다.** 코랩 코드는 구글 서버에서 실행되므로 교사 컴퓨터의 내부 IP에 닿지 않습니다. VS Code 등 학생 컴퓨터에서 실행합니다.
- 학생 브라우저에서 `http://교사IP:8000/`을 열어 `{"status": "ok", ...}`가 보이는지 먼저 확인합니다.
- 안 보이면: 교사 컴퓨터 방화벽에서 Python의 들어오는 연결을 허용했는지, 같은 네트워크인지 확인합니다. 학교 무선망은 기기끼리 통신을 막아 두기도 합니다.

## 메뉴 표기

알레르기 번호 표기는 학교마다 다릅니다. `clean_menu`는 `김치9.`와 `김치 (9)`를 처리하지만 `지파이(7)`처럼 띄어쓰기 없는 괄호는 번호가 남습니다. 수업 전에 우리 학교 메뉴로 확인하고, 필요하면 활동지와 해설지의 함수를 고칩니다.

## 기록과 보안

- 서버 화면에는 시각, IP, 서비스 이름, 결과 코드만 나옵니다. 저장하지 않습니다.
- 학생 정보를 다루지 않습니다. 급식, 시간표, 학사일정은 공개 데이터입니다. 알레르기 등 건강 정보를 코드에 쓰지 않도록 안내합니다.
