# Claude API 수업 서버

학생들이 공식 `anthropic` 라이브러리로 Claude API 프로그램을 만드는 수업에 쓰는 서버와 노트북입니다.
서버는 교사 컴퓨터에서 실행하며, 실제 API 키를 학생에게 주지 않고 모델과 사용량을 제한합니다.
서버 실행에는 파이썬만 있으면 됩니다.

| 파일 | 내용 |
|---|---|
| `server.py` | 서버 |
| `setup.sh` / `setup.bat` | `config.json` 만들기 (Mac / Windows) |
| `start.sh` / `start.bat` | 수업 때 서버 켜기 (Mac / Windows) |
| `notebooks/Claude_API_활동지.ipynb` | 학생용. 코드 없이 빈 칸만 있고, 교사 설명을 들으며 따라 칩니다. 채팅 수업 뒤에 하며, 마지막에 채팅 서버 코드를 복사해 `ask`로 고쳐 챗봇 서버 코드를 만듭니다. 실행은 학생 선택입니다. |
| `notebooks/Claude_API_해설지.ipynb` | 교사용. 코드가 채워져 있습니다. 학생에게 주지 않습니다. |

활동지는 클래스룸 등으로 따로 나눠 줍니다.

## 설정: setup (처음 한 번)

```bash
./setup.sh
```

`config.example.json`으로 `config.json`을 만듭니다. Windows는 `setup.bat`을 더블클릭합니다. 묻는 것은 없습니다.

다른 컴퓨터로 복사한 뒤 권한 오류가 나면 `chmod +x setup.sh start.sh`를 한 번 실행합니다.

## 수업: start

터미널에서 실행합니다. Windows는 `start.bat`을 더블클릭합니다.

```bash
./start.sh
```

실제 API 키를 물은 뒤(파일에 저장하지 않아 켤 때마다 입력합니다) Claude에게 수업용 키를 받아 서버를 열고, 접속 주소, 수업용 키, 모델을 화면에 안내합니다. 이 내용을 학생들에게 알려 줍니다.

- 수업용 키는 `i-am-a-teacher`처럼 짧은 영어 문장이며, **서버를 켤 때마다 바뀝니다.** 파일에 저장하지 않습니다. 다시 켰다면 학생들에게 새 키를 알려 줍니다.
- 수업용 키를 받을 때 아주 적은 요금이 나갑니다. 실패하면 이유를 알리고 서버가 켜지지 않습니다.
- 사용 횟수 제한은 서버를 켤 때마다 0부터 다시 셉니다. 켜고 끄는 단위가 곧 수업 단위입니다. 학생은 IP로 구분합니다.
- 수업이 끝나면 터미널 창에서 `Ctrl+C`로 끕니다.

## 설정 파일

`config.json`은 setup이 `config.example.json`을 복사해 만들고, git에서 제외됩니다. 값을 바꾸려면 이 파일을 직접 고치고 서버를 다시 켭니다. API 키는 저장하지 않습니다. 모델을 바꾸면 활동지와 해설지 코드의 모델 이름도 함께 고칩니다.

| 항목 | 뜻 |
|---|---|
| `model` | 지원할 모델. 다른 모델을 요청하면 지원하지 않는다고 안내합니다. |
| `max_tokens` | 응답 길이의 상한. 학생이 더 크게 요청해도 이 값으로 줄입니다. |
| `port` | 서버 포트 |
| `limit_per_minute` | 학생(IP) 한 명의 분당 요청 수 |
| `limit_per_student` | 이번 수업에서 학생(IP) 한 명의 요청 수. 프로젝트 수업에서는 100 정도로 올립니다. |
| `limit_per_class` | 이번 수업의 전체 요청 수 |
| `max_concurrent` | 동시에 보내는 API 호출 수. 나머지 요청은 줄 서서 기다림 |
| `max_input_chars` | 요청 한 번의 입력 글자 수 |

## 지원하는 API

공식 API와 같은 형식입니다.

- `POST /v1/messages`: `model`, `max_tokens`, `messages`, `system`, `temperature`, `top_p`, `stop_sequences`. 글자만 지원합니다. 스트리밍, 도구, 이미지 등은 지원하지 않는다고 안내합니다.
- 생각 기능: Haiku 모델은 끄고, 다른 모델은 응답에서 생각 블록을 뺍니다. 그래서 `response.content[0].text`가 항상 답입니다. 실제 API를 직접 쓸 때는 첫 블록이 생각 블록일 수 있습니다.
- `GET /v1/models`: 지원하는 모델 목록. API 호출이 없어 비용이 들지 않으므로 접속 테스트에 씁니다.

## 학생이 한꺼번에 요청할 때

- 동시 호출은 `max_concurrent`개로 묶이고, 나머지 요청은 차례를 기다립니다.
- API가 한도 초과(429)나 과부하(529)를 알리면 기다렸다가 자동으로 다시 시도합니다(요청당 최대 5번 호출).
- 줄 서기와 재시도를 합쳐 100초 안에 끝나지 않으면 학생에게 "지금 사용자가 많아요"라고 안내합니다(529).
- 화면에 `혼잡`이 자주 보이면 Anthropic 콘솔에서 계정의 사용 한도를 확인하고 `max_concurrent`를 줄여 봅니다.

## 학생 컴퓨터에서 접속이 안 될 때

- **코랩은 접속할 수 없습니다.** 코랩 코드는 구글 서버에서 실행되므로 교사 컴퓨터의 내부 IP에 닿지 않습니다. VS Code 등 학생 컴퓨터에서 실행합니다.
- 학생 브라우저에서 `http://교사IP:8000/`을 열어 `{"status": "ok"}`가 보이는지 먼저 확인합니다.
- 안 보이면: 교사 컴퓨터 방화벽에서 Python의 들어오는 연결을 허용했는지, 같은 네트워크인지 확인합니다. 학교 무선망은 기기끼리 통신을 막아 두기도 합니다.
- 교사 IP는 네트워크에 다시 접속하면 바뀔 수 있으므로 수업 전에 서버 화면에서 확인합니다.

## 기록과 보안

- 서버 화면에는 시각, IP, 토큰 수만 나옵니다. 학생이 쓴 내용은 저장하거나 표시하지 않습니다.
- 수업 때만 켜 두고, 비용은 `limit_per_class`와 `max_tokens`로 제한합니다. Anthropic 콘솔에서 월 사용 한도도 함께 걸어 두면 안전합니다.
- 입력한 내용은 Claude API로 전달되므로 학생에게 개인정보를 입력하지 말라고 안내합니다.
